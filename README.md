# 🛒 Super Ofertas

**Tu supermercado, a un toque de distancia.**

Una app de delivery de supermercado donde los clientes arman su compra y los pickers la preparan, todo en la misma aplicación.

| 🌐 | **Axios** | Comunicación con el servidor |
